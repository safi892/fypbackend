# Suggested implementation order (don't skip around)

This order minimizes rework and lets you test each layer independently:

### Sprint 1 — Foundation

* Refactor the FastAPI project into a modular structure.
* Add request/response schemas.
* Add logging and configuration.

### Sprint 2 — Static Analysis

* Integrate a C++ parser (preferably Tree-sitter C++).
* Implement:

  * Function detection
  * Recursion detection
  * Loop and nested-loop detection
  * Function length
  * Missing comments/documentation
* Return structured JSON only (no AI yet).

### Sprint 3 — Code Change Analysis

* Accept old and new code.
* Compare functions and report additions, removals, and modifications.
* Compute simple complexity differences.

### Sprint 4 — AI Integration

* Load your code review model.
* Feed it the code plus analyzer output.
* Generate:

  * Review suggestions
  * Comments
  * Documentation
  * Explanations

### Sprint 5 — Translation

* Integrate the English → Roman Urdu model.
* Translate only the generated text when requested.

### Sprint 6 — Reporting

* Merge outputs into a single review report.
* Add confidence levels (if available), timing information, and clear formatting for the frontend.

## One architectural improvement

Instead of letting the AI "discover" everything from raw code, **always let the static analyzer produce structured facts first**, then pass both the **original code** and the **analysis JSON** to the AI model.

For example:

```json
{
  "analysis": {
    "recursive": true,
    "nested_loops": 2,
    "long_functions": ["calculateSalary"],
    "missing_comments": 3
  },
  "code": "..."
}
```

This hybrid design has several advantages:

* More accurate suggestions because the AI receives explicit facts.
* Lower inference cost since the model doesn't need to infer simple structural properties.
* Easier debugging because you can inspect the analyzer output independently.
* Simpler future extensions when you add Java or Python—you only replace the parser, while the review model and backend remain largely unchanged.
